# Data Science for the Environment

**BI 410/510L · University of Oregon**  
Lauren Ponisio

A hands-on introduction to working with environmental data in **R**. We use real ecological and climate datasets to learn reproducible data analysis, visualization, simulation, and collaborative workflows.

[**Read the textbook**](./docs/index.html) · [Course source files on GitHub](https://github.com/lponisio/ds-environ)

## In this book

Explore key programming concepts, data wrangling and visualization with the tidyverse, simulation-based hypothesis testing, Git and GitHub, ecological networks, spatial data, and reproducible research practices.

The chapters include worked examples, demonstrations, and labs designed to help you apply each skill to environmental questions.
